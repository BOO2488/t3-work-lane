Qwen 云端调用脚本集合

scripts/：施工、可变车道、潮汐车道和双任务筛选脚本，以及结果导出工具。
scripts/tools/：流式施工筛选。
model/：云端适配器和本机 EAS 配置。仓库中只提供配置模板，请通过环境变量设置 EAS_ENDPOINT、EAS_TOKEN、EAS_MODEL。
rules/、outputs/rule.md：筛选规则及相关示例图片。

安装：python3 -m pip install -r requirements.txt
启动双任务（替换输入路径）：
INROOT=/你的原始数据目录 bash scripts/run_qwen_dual_filter_batch.sh
启动施工影响筛选：
INROOT=/你的原始数据目录 bash scripts/run_qwen_lane_impact_batch.sh
启动潮汐车道筛选：
INROOT=/你的原始数据目录 bash scripts/run_qwen_tidal_lane_batch.sh
查看可变车道/潮汐车道图片筛选参数：
python3 scripts/qwen_lane_marking_visual_filter.py --help

从其他目录运行时，用本目录内脚本的绝对路径。
服务通过 EAS_ENDPOINT、EAS_TOKEN、EAS_MODEL 配置；需要网络可访问服务。
云端方式不需要本地 GPU、模型权重、torch 或 transformers。
主要入口已改为读取包内适配器和配置。输入数据须符合各脚本要求。
历史批次（remaining、review、readme 等）仍有原始数据、参考图和输出的固定路径，复用时应检查参数或改路径。
未调用远程模型测试；整理过程不会产生推理请求。
