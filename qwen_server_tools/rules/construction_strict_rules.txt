城市施工道路场景严格筛选规则

目标场景
只保留“近中距离内会影响自车正常行驶路径”的城市施工道路场景。
判断核心不是颜色，也不是单纯出现围挡/锥桶/水马，而是施工设施是否实际进入或压缩机动车通行空间，是否使自车需要减速、绕行、并线、变道或按临时路径通行。

一、必须保留的场景
满足以下任一类，可保留：

1. 当前车道或相邻车道被施工设施占用
- 施工围挡、水马、防撞桶、锥桶阵列、施工车辆、施工机械等进入机动车道。
- 原本可通行的车道被封闭、压缩或部分占用。
- 自车前方近中距离内出现封闭端头、施工隔离端头、临时通行缺口。

2. 明确改变自车行驶路径
- 出现临时导流、绕行、并线、车道收窄。
- 锥桶/水马/导向设施形成连续边界，迫使车辆改变行驶轨迹。
- 车辆需要从原车道切换到旁侧车道，或沿临时通道通过。

3. 近中距离存在施工作业区并影响通行
- 作业区贴近或侵入机动车道。
- 施工人员、施工机械、工程车辆位于车道内或车道边界内侧。
- 作业区与自车行驶路线之间只有临时隔离设施，且通行空间明显变窄。

4. 施工预警与导向设施服务于当前通行变化
- “前方施工”“车辆慢行”“限速”等施工标志出现在自车即将经过的位置。
- LED/发光箭头/导向牌/黄黑导向板明确指示当前车辆绕行或变道。
- 预警设施与占道、封闭、导改同时出现。

二、必须删除的场景
出现以下情况，即使画面中有施工相关物体，也删除：

1. 路边长期围挡，不影响机动车道
- 围挡在人行道、绿化带、建筑红线内、路外区域。
- 主车道宽度正常，车流正常直行，无需绕行或变道。
- 只是道路右侧或左侧长期施工围挡，但没有侵入车道。

2. 远处施工不算
- 施工设施只在远处背景出现。
- 自车当前近中距离行驶路线没有受到影响。
- 远处可见吊车、施工楼体、围挡、导向牌，但当前车道正常通行。

3. 单独锥桶/水马不算
- 少量锥桶、水马只是路边摆放、临时占位、停车隔离。
- 锥桶/水马没有形成连续导流边界。
- 锥桶/水马没有造成车道收窄、封闭、绕行、并线。

4. 普通道路设施不算施工
- 普通中央护栏、桥梁护栏、绿化隔离栏、永久隔离栏。
- 普通交通标志、普通道路指示牌、路灯、信号灯。
- 普通收费站、检查站、停车隔离设施，除非明确形成施工导改。

5. 普通车辆或作业车不算
- 普通货车、工程外观车辆、清扫车、养护车单独出现，不算。
- 车辆停在路边或正常行驶，不影响自车通行，不算。
- 必须同时看到施工占道、封闭、导改或作业区侵入车道，才可保留。

6. 建筑施工不算道路施工
- 只看到塔吊、脚手架、建筑工地、楼体施工。
- 工地围挡在道路外侧，不影响机动车行驶。
- 建筑施工背景不能作为保留理由。

7. 工人单独作业不算
- 只有工人、反光背心、安全帽，但没有车道封闭或导改，不算。
- 工人在路边、人行道、绿化带作业，不影响机动车道，不算。

三、距离要求
只看自车近中距离内的影响：

1. 近距离
- 画面下半部或前方马上到达区域。
- 自车即将通过，必须减速、避让、绕行或并线。

2. 中距离
- 前方可见明确施工占道、封闭端头或导流路径。
- 按当前行驶方向继续前进会进入施工影响区域。

3. 远距离
- 只在画面远端或背景可见施工设施。
- 当前车道还未受影响。
- 一律不作为保留依据。

四、空间关系优先级
筛选时优先判断空间关系，而不是颜色或物体名称。

优先级从高到低：
1. 是否侵入当前机动车通行空间。
2. 是否导致车道收窄、封闭、绕行、变道或并线。
3. 是否位于自车近中距离，而不是远处背景。
4. 是否有连续导流或封闭体系，而不是孤立设施。
5. 颜色、材质、设施类型只作为辅助判断。

五、保留判定模板
一个 clip 只有在至少一帧满足以下判断时才保留：

- 近中距离可见施工设施进入机动车道；并且
- 当前或相邻车道通行空间被压缩、封闭或导改；并且
- 自车继续行驶会受到影响，需要减速、绕行、并线或沿临时路径通过。

六、删除判定模板
满足以下任一条，删除整个 clip：

- 所有帧都只是路边围挡，车道正常。
- 所有帧都只是远处施工，近中距离无影响。
- 所有帧都只是普通护栏、路边杂物、停车隔离。
- 所有帧都只有少量锥桶/水马，未形成导改。
- 所有帧都只有建筑工地、塔吊、脚手架，未影响车道。
- 所有帧都只有工人或车辆，未形成施工占道。

七、正负例口径
正例：施工围挡或隔离设施贴近/侵入车道，前方有导向隔离或封闭端头，自车行驶路径明显被改变。
负例：围挡位于路边、人行道、隔离带或远处，机动车道保持正常宽度和方向，自车无需绕行或变道。

一句话规则
只保留“施工设施实际改变自车通行路径”的 clip；凡是不影响当前车辆行驶的路边围挡、远处施工、普通设施、孤立锥桶/水马，全部删除。

八、重点强正例：路中间封闭端头
以下类型必须优先保留，是最符合目标的施工路段：

1. 施工设施位于道路中间或当前车道前方
- 锥桶、水马、施工牌、导向牌、限速牌、告示牌横向摆放在车道内。
- 设施形成明显封闭端头，阻断原本直行路径。
- 自车继续前进会被迫减速、停车、绕行或变道。

2. 多个设施组合形成施工控制区
- 锥桶阵列 + 施工告示牌。
- 水马/围栏 + 黄黑导向板。
- 限速牌 + “道路施工/车辆慢行”牌 + 锥桶。
- 施工牌、导向牌、锥桶横向占据一条或多条车道。

3. 斑马线、路口、车道中央的施工封控
- 斑马线前方摆放施工牌、锥桶、水马。
- 路口中央或车道中央出现施工封闭设施。
- 对车辆通行方向产生直接限制。

这类场景即使没有大面积围挡，也应保留，因为它直接影响车辆行驶路径。
